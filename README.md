# Kiruththika Kukanesvaran — Dynamic Portfolio

A responsive, animated portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

For best results, use a local server (VS Code Live Server is ideal).

## Deploy for free
### GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Go to Settings → Pages.
4. Select the main branch and `/root`.
5. Save. GitHub will provide the live portfolio URL.

### Netlify / Vercel
Drag the folder into a compatible deployment workflow or import the GitHub repository.
